# Desktop Eye Tracker

Десктопное приложение для отслеживания положения глаз и направления взгляда с помощью веб-камеры.

Проект использует компьютерное зрение для обнаружения лица и ключевых точек глаз, после чего анализирует положение взгляда пользователя.

## Возможности

* получение изображения с веб-камеры;
* обнаружение лица;
* отслеживание положения глаз;
* определение направления взгляда;
* обработка видеопотока в реальном времени;
* визуализация результатов отслеживания.

## Принцип работы

Приложение получает видеопоток с подключённой веб-камеры.

Далее выполняются следующие этапы:

1. Захват кадра с камеры.
2. Обнаружение лица пользователя.
3. Поиск ключевых точек лица и глаз.
4. Анализ положения глаз.
5. Определение направления взгляда.
6. Отображение результатов обработки.

## Технологии

Проект разработан с использованием технологий компьютерного зрения и Python.

Основные используемые библиотеки:

* Python

В зависимости от версии проекта также могут использоваться дополнительные библиотеки для обработки изображений и работы с интерфейсом.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dalzhin1isp23/desktop-eye-traker.git
```

Перейдите в папку проекта:

```bash
cd desktop-eye-traker
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Запустите основной файл приложения:

```bash
python main.py
```

После запуска программа запросит доступ к веб-камере и начнёт обработку видеопотока.
